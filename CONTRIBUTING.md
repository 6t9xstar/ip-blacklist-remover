# Contributing

Thanks for taking the time to contribute.

## Getting started

1. Fork the repository and clone your fork.
2. Create a branch: `git checkout -b feat/your-change`.
3. Make your change, keeping it focused on one thing.
4. Commit with a clear message and open a pull request.

## Guidelines

- Keep pull requests small and reviewable.
- Explain the problem your change solves, not just the change.
- Never commit secrets, API keys or credentials.
- Match the existing code style in the files you touch.

## Reporting bugs

Open an issue describing what you expected, what happened, and the steps to
reproduce it.
